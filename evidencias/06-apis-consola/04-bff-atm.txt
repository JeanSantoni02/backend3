Backend dedicado a los cajeros. Es el unico que ejecuta operaciones sobre el
dinero, por lo tanto el unico con autenticacion. Cada terminal se identifica
en cada peticion con su credencial.

Swagger UI: http://localhost:8083/swagger-ui.html
Servicio activo, se identifica como: Banco XYZ - BFF Cajeros

  POST http://localhost:8083/bff/atm/cuentas/150/retiro
  X-ATM-Terminal: ATM-001
  X-ATM-Key: clave-demo-001
  body: {"monto":200000,"referencia":"EVID-SALDO"}

  HTTP 422   (0.045570 s)

  {"codigo":"SALDO_INSUFICIENTE","mensaje":"saldo insuficiente para el monto solicitado","entregarEfectivo":false,"referencia":null}

  NOTA: Devuelve 422 y no 400: la peticion esta bien formada, es el negocio el que no puede cumplirla. El cajero usa esa diferencia para ofrecer el maximo disponible en vez de pedir otro monto a ciegas.

Codigos HTTP usados y por que:
  400  peticion mal formada o monto que el cajero no puede entregar
  401  terminal no autorizado
  404  la cuenta no existe
  409  no se pudo confirmar el retiro: NO entregar efectivo, conciliar
  422  peticion correcta que el negocio no puede cumplir
  503  el servicio de dominio no responde
